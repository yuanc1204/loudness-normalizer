视频音量均衡 —— 使用说明
================================

这个工具能把视频里忽高忽低的声音拉平：
整体音量统一，段落之间的音量差距压缩到一定范围内。
画面不会重新编码，画质无损，速度快。

【最简单的用法】
  把视频文件直接拖到「响度均衡.bat」图标上，松手即可。
  处理完的视频统一放在本文件夹的「输出」子文件夹里，文件名不变
  （不同文件夹里的同名视频会自动加序号，不会互相覆盖）。

【批量处理】
  方法一：把一堆视频文件一起选中，拖到「响度均衡.bat」上。
  方法二：把视频都放进本文件夹，然后双击「响度均衡.bat」。

【进阶：命令行参数】（在本文件夹打开终端）
  python 响度均衡.py 视频.mp4                  处理单个文件
  python 响度均衡.py --mode gentle 视频.mp4    温和模式：只统一整体音量，
                                           保留原始的强弱起伏（适合音乐、电影）
  python 响度均衡.py --target -14 视频.mp4     目标响度调大一点（数字越接近 0 越响）
  python 响度均衡.py --lra 10 视频.mp4         允许更大的音量波动范围
  python 响度均衡.py --denoise high 视频.mp4   强力降噪（录音噪声明显时用）
  python 响度均衡.py --denoise off 视频.mp4    关闭降噪（音质干净的片源）

  默认设置：strong 模式，目标 -16 LUFS，波动范围 ≤7 LU，标准降噪，
  适合说话声忽大忽小的视频（课程、访谈、录屏等）。
  降噪在提升音量之前进行，小声段抬上来的是人声而不是环境噪声；
  说话间隙的底噪也不会被抬响。

【注意事项】
  · 原视频不会被修改，输出的是新文件。
  · avi / flv / wmv 等旧格式会自动转存为 mp4 容器（画面依然不重编码）。
  · 需要电脑上装有 ffmpeg（你已经装好了）。
