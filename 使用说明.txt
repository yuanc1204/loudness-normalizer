视频音量均衡 —— 使用说明
================================

把视频里忽高忽低的声音变均衡：自动把视频切成响度段，
小声的段整段提升、大声的段基本不动，段内的自然起伏原样保留，
增益变化藏在说话停顿处，最后整片统一到目标响度。
大声段的环境音几乎不会被抬高，听感自然。
画面不重新编码，画质无损，速度快。

【最简单的用法】
  把视频文件直接拖到「响度均衡.bat」图标上，松手即可。
  处理完的视频统一放在本文件夹的「输出」子文件夹里，文件名不变
  （同名视频会自动加序号，不会互相覆盖）。

【批量处理】
  方法一：把一堆视频文件一起选中，拖到「响度均衡.bat」上。
  方法二：把视频都放进本文件夹，然后双击「响度均衡.bat」。

【进阶：命令行参数】（在本文件夹打开终端）
  python 响度均衡.py 视频.mp4                  处理单个文件
  python 响度均衡.py --target -14 视频.mp4     目标响度调大一点（数字越接近 0 越响）
  python 响度均衡.py --denoise high 视频.mp4   强力降噪（录音噪声明显时用）
  python 响度均衡.py --denoise off 视频.mp4    关闭降噪（音质干净的片源）
  python 响度均衡.py --jobs 5 文件夹           同时处理 5 个（默认 3 个并行）
  python 响度均衡.py --strength 0.95 视频.mp4  均衡力度 0~1（默认 0.85，越大越平）
  python 响度均衡.py --mode press 视频.mp4     旧方案：持续压大声、不抬小声
                                           （段内也会被碾平，环境音全程均匀变大）
  python 响度均衡.py --denoise dfn 视频.mp4    DeepFilterNet 神经网络降噪：
                                           压环境音、保人声（含呼吸声等 ASMR 类
                                           声音），输出为单声道。
                                           环境音最多被压 --atten-lim dB（默认 10），
                                           人声就算被误判，损失也不会超过这个数；
                                           调大压得狠（如 --atten-lim 20），调小更保险

  默认设置：目标 -16 LUFS，标准降噪，3 个并行。

【注意事项】
  · 原视频不会被修改，输出的是新文件。
  · avi / flv / wmv 等旧格式会自动转存为 mp4 容器（画面依然不重编码）。
  · 需要电脑上装有 ffmpeg。
